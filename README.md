# CinéExplore 🍿

CinéExplore est une mini-application web de démonstration qui aide à explorer une petite sélection de films fictifs. Elle a été conçue comme projet scolaire, avec une interface sombre, moderne et adaptée aux petits écrans.

## Fonctionnalités

- Cartes de films avec titre, année, genre et résumé.
- Recherche par titre en temps réel.
- Filtre par genre.
- Fiche détaillée en cliquant sur une carte.
- Message lorsque la recherche ne renvoie aucun résultat.
- Données de démonstration intégrées : aucune API, aucun compte et aucune clé secrète.
- Affiches graphiques créées en CSS, donc pas besoin d'images externes.

## Technologies

- HTML5
- CSS3
- JavaScript natif (sans framework)

## Lancer le projet sur son ordinateur

1. Télécharge ou copie les fichiers du projet dans le même dossier.
2. Ouvre `index.html` dans un navigateur récent (Chrome, Edge, Firefox, etc.).
3. La recherche et le filtre fonctionnent sans serveur.

## Publier sur GitHub Pages

1. Connecte-toi à GitHub et crée un dépôt public nommé `cine-explore`.
2. Ajoute `index.html`, `style.css`, `script.js`, `README.md` et `SPEC.md` à la racine du dépôt.
3. Dans le dépôt, ouvre **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Choisis la branche `main` et le dossier `/(root)`, puis clique sur **Save**.
6. Attends la fin du déploiement. L'adresse sera généralement `https://TON-NOM-GITHUB.github.io/cine-explore/`.

Remplace `TON-NOM-GITHUB` par ton identifiant GitHub.

## Note

Les films et leurs résumés sont fictifs et servent uniquement à la démonstration. Les affiches sont réalisées en CSS et ne représentent pas de vraies affiches de films.
